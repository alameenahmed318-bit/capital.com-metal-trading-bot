# ADSS QuantEdge V1

EA for ADSS MT5. Demo-first.

- M5 entry timeframe + H1 trend filter
- EMA 20/50/200
- RSI + ADX confirmation
- ATR-based SL/TP
- Dynamic position sizing
- Break-even + ATR trailing
- Spread/session filters
- One position per symbol by default
- Cooldown between entries
- No Grid / Martingale / Averaging

Default risk: 0.50% of equity per trade.
