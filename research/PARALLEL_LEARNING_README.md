# Persistent monitoring learning
Research only: separate from trading and existing master permits. The owner-only read endpoint reads saved backtest settings and fully closed, fee-complete positions scoped by exact symbol and client. Historical test slippage is included in validation threshold calibration; strategy-only results are not represented as new-model labels. A small logistic outcome model is fit on prior closed positions, with entry features known before entry and purged chronological validation; its held-out performance is reported, not used as execution permission or causal model credit. The worker saves matured forecast outcomes and outstanding predictions to an atomic local JSON file outside the repo under .alzool-parallel-learning, scoped by hashed owner/client/symbol. Model weights are refit at restart; no passwords saved. Market with no fresh MT5 context skips training. Failed old tree fits back off six hours, while existing fitted trees are preserved and heavy model failures back off ten minutes. New-model sustained negative nonoverlap research outcomes may pause that model for six hours; no permanent deletion or live weight changes. Real broker costs cannot be reliably attributed to individual shadow models. Local runtime update/restart is necessary.
