# AL-ZOOL parallel monitoring pilot
The existing seven-model worker and all existing execution and profit logic remain unchanged. New optional worker publishes only to owner-only parallel-monitor, never live-forecast. Separate in-memory cache, no DB writes or migration. New section on Master AI reads the independent cache every 20 seconds while visible. TCN, official HF PatchTST, lightweight multivariate LSTM, compact patch Transformer, simple LSTM and Isolation Forest are trained in the new worker; Ensemble is derived server-side with family budgets and no extra vote. Existing TimesFM, Chronos, TiRex and trees stay in original worker. This is a new lightweight live-monitor architecture, not the exact previously tested weights. No new model can influence real trade decisions. Research weights and outcomes are provisional proxy metrics using three closed bars and approximate spread costs, not broker P&L; in-memory stats reset on restart. Training every six hours, one CPU thread, below-normal priority; training can interrupt the new worker's own forecasts but never waits in existing master. CPU overhead not benchmarked on owner's laptop. Install only in separate environment and only after the server branch is reviewed and deployed. No secrets in Git.
