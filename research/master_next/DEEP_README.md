# Deep challengers and extended training
Research only. No live model changes, no MT5 execution. Three seeds per model. 40 epochs for a multivariate LSTM, TCN and a compact patch-based Transformer inspired by PatchTST (not official PatchTST). Ensemble compared with momentum and optional Isolation Forest; thresholds selected only on validation and both directions required. PPO/DQN V2 extended to 32768 steps per seed. This reuses inspected fixtures in development mode; no independent claims. Additional compute is not evidence of learning generalization. For actual fresh holdout use export_archive.py from V2 in a separate worktree and run deep_challengers.py without --development on private archive; do not commit private candles. Kronos, Chronos-2 fine-tuning, Moirai 2, IQL/CQL and Decision Transformer are future candidates, not implemented here. Existing TimesFM runs were frozen inference, not weight training. FinBERT requires timestamped news; cloud review requires opt-in and keys.
