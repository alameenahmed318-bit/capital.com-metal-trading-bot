Built on fix/connection-resilience-20261127; production branch is unchanged.

- Replacement advisers: XGBoost, TiRex-2, CatBoost, Chronos-Bolt Tiny, TCN, LSTM Multi, Patch Transformer. LightGBM, TimesFM-2.5 and Chronos-2 are excluded from this pilot entry panel; research workers/reports are not deleted.
- Native MT5 DEMO account telemetry, M1 and terminal demo capability are required. REAL, CONTEST, UNKNOWN and disabled environment toggle never use this route. Existing strategy, price, authorization, position capacity and post-close checks remain.
- Install optional dependencies from marketplace/backend/requirements-hybrid-demo.txt in the pilot backend environment; do not install on the existing live service until resource headroom is verified. Set ALZOOL_HYBRID_DEMO=1 for an explicitly reviewed demo service only. Keep default off. Run existing parallel worker for the three new inputs.
- Until 150 matured live quote observations accumulate, the agreed seven provide a provisional non-learned direction; trained CatBoost/XGBoost select one direction once available, recalibrating their blend on a chronological split. No synchronously awaited training or inference: bounded background queue, snapshot expiry, CPU thread limit. When a prediction is absent/stale, the provisional panel is used; no older-bar order.
- A model with 60 nontrivial observations and negative net quote proxy in each of the last two groups of 30 is excluded from the pilot, not erased. Further monitoring can rehabilitate it. The 0.30 ATR stress cost is illustrative, not actual broker commission. The existing three removed advisers remain outside this pilot independently of retirement.
- Data is saved locally under ALZOOL_META_STATE_DIR (default ~/.alzool-meta-demo). Use persistent storage if restart retention is required; state is exact client/symbol scoped. The models are retrained from saved samples, not loaded from untrusted serialized objects.
- The entry learner uses subsequent observed bid/ask price counterfactuals, **not actual trade profit labels**. It does not yet control exits, add-on/cooling/recovery. Demo exposure is still experimental; no validated profitability claim. Existing order protection settings are unchanged.
- Run syntax and regression checks before deployment; GitHub CI is provided. Current hosted service, local MT5 and workers are not changed by committing this branch.
