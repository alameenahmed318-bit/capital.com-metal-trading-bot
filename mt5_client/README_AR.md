# AL-ZOOL Central Client — عميل MT5

هذا الملف **ليس جسراً للقراءة فقط**. يرسل بيانات السوق وحساب MT5
إلى المحرك المركزي، ويستقبل قراراته. يستطيع إرسال أوامر فتح
وتعديل وإغلاق المراكز عند تشغيل المفاتيح المناسبة وبوجود موافقة المحرك.

## أثناء الإعداد
- اسم الملف: `ALZOOL_Central_Client.mq5`.
- خادم المشروع: `https://al-zool-central-engine.onrender.com`.
- سجل الدخول والترخيص محفوظ على جهاز MT5؛ لا تشارك مفتاح الاقتران.
- أضف عنوان الخادم إلى قائمة WebRequest في MT5.
- اترك `InpEnableCentralTrading=false` و
  `InpEnableCentralPositionManagement=false` أثناء الفحص.
- Compile في MetaEditor باستخدام F7، ويجب ظهور 0 errors.
- بعد كل تعديل في GitHub يجب إعادة تجميع EA وتركيب نسخة EX5 الجديدة يدوياً.
- ابحث في Experts عن `telemetry_http_ms` و`decision_http_ms` لفحص زمن الربط.

## المتطلبات قبل تفعيل التداول
اختبارات Demo موثقة لموافقة المجلس، منع الأوامر المكررة، سقوف اللوت،
التعافي ×3، إغلاق المجموعة عند فشل إحدى الصفقات، انقطاع الشبكة،
وتعطل Ollama/Render. النشر على Render وحده لا يحقق هذه المتطلبات.
