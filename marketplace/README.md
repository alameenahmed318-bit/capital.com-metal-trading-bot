# UAE Market — Marketplace v2

تم تنفيذ المرحلة الثانية للمتجر.

## الموجود الآن
- بيانات منتجات منظمة.
- سلة محفوظة في الهاتف عبر localStorage.
- الكميات والمخزون الأساسي.
- صفحة Checkout.
- إنشاء رقم طلب وتجهيز بيانات العميل.

## التكامل الحقيقي التالي
- Backend/API مستضاف.
- قاعدة بيانات حقيقية.
- إعادة حساب السعر والمخزون على الخادم.
- Stripe Checkout/Payment Links في Sandbox أولاً.
- Stripe webhook لتأكيد الدفع.
- إنشاء Order بعد نجاح الدفع.
- إرسال الطلب إلى UAE Business AI Agent.
- HubSpot CRM.
- الشحن والتتبع.

**أمان:** مفاتيح Stripe السرية لا توضع داخل ملفات الواجهة أو GitHub Pages.

> ملفات التداول الحالية خارج هذا المجلد ولم يتم تعديلها.
